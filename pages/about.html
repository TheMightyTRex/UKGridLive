About UK Grid: Live+

A redesign based on Kate Morley's National Grid: Live

UK Grid: Live+ takes the concept and data pipeline design of Kate Morley's National Grid: Live and rebuilds it with dark mode, longer historical ranges, dedicated pages per energy type, live-wired pages for over a dozen other countries, and a cross-country comparisons tool. It is not affiliated with National Grid plc, NESO, Elexon, EirGrid, or Kate Morley herself.

Source code

UK Grid: Live+'s source is public on GitHub at github.com/TheMightyTRex/UKGridLive - the frontend, the PHP/MySQL ingestion pipeline, and the deployment guide. There is no separate open-source licence attached to the repository; the only redistribution terms that apply are the ones the data APIs themselves require, such as Elexon's BMRS attribution statement in the footer below (see the Sources page for each API's own terms).

One source is a step stricter than the rest: the Australia (NEM) page's grid data comes from the Open Electricity API (formerly OpenNEM), whose data is licensed CC BY-NC 4.0 - non-commercial use only, with attribution - rather than the unrestricted or attribution-only terms every other source on this site is used under. See the Sources page for the full breakdown of every source and its own terms.

Credit to Kate Morley

UK Grid: Live+ is a redesign built on the concept, data pipeline design, and public-domain groundwork of National Grid: Live at grid.iamkate.com, created by Kate Morley. The original source code is published on GitHub under the CC0 1.0 Universal licence, meaning Kate has waived copyright to the extent possible under law.

This project reuses her choice of data sources and much of the original site's spirit - a concise, accessible, public-facing view of the grid - while adding the features above. If you find this kind of tool useful, consider supporting Kate directly via Ko-fi, since she covers the hosting costs of the original, far more popular, site.

Why the numbers differ from grid.iamkate.com

Both sites pull from the same three public GB data feeds - the Elexon Insights Solution, the National Energy System Operator's Data Portal, and the Carbon Intensity API - so most figures should be close. But a few, especially the headline demand figure, can be some way off. Here is why.

Demand is calculated differently

grid.iamkate.com does not fetch a published demand statistic at all. Its "Demand" figure is calculated in code as total generation plus net interconnector imports - an energy-balance figure derived from the same generation data it displays elsewhere on the page. UK Grid: Live+ instead fetches Elexon's own separately-published Transmission System Demand Outturn figure directly from the Insights Solution's /demand/outturn endpoint. These are two genuinely different quantities, built from different accounting methods, so they can diverge by a noticeable margin - occasionally a few gigawatts - even when both sites are otherwise in sync. Neither figure is "wrong"; they are just answering a slightly different question.

Different refresh timing

grid.iamkate.com's own update script runs on a five-minute schedule. UK Grid: Live+ refreshes on demand - the first visitor after a source's data goes stale triggers a fresh pull, which in practice lands somewhere in the 15-30 minute range. Comparing the two sites at any single moment can catch them mid-way through different update cycles, especially for fast-moving figures like price and generation mix.

What matches closely

Generation by fuel type, wholesale price, and carbon intensity use the same underlying sources and broadly the same methodology on both sites, including folding in embedded solar and wind from NESO's data portal and excluding battery storage output from the generation total to avoid double-counting. Small gaps here are almost always down to the refresh-timing difference above, or to NESO retrospectively revising an estimate after publication, rather than a difference in how the number is calculated.
